## ⚡ CORE CRAFTSMANSHIP INVARIANTS

### 1. Sub-1.2s Core Web Vitals Discipline (LCP, CLS, INP)
- **Largest Contentful Paint (LCP):** Must resolve under 1.2s (75th percentile). Hero assets must use `<link rel="preload">` with modern AVIF/WebP formats.
- **Cumulative Layout Shift (CLS):** Must be exactly 0.000. All images, iframes, and dynamic containers must declare explicit `width`, `height`, or `aspect-ratio` CSS to reserve viewport space before download.
- **Interaction to Next Paint (INP):** Sub-100ms response. Heavy scripting must be deferred (`defer` / `async` or Web Workers) to prevent main-thread thread jank.

### 2. Machine-Readable Semantic Knowledge Graph (Schema.org JSON-LD)
- Every indexable page must contain valid `<script type="application/ld+json">` declaring structured entities.
- Must accurately map entities (`Organization`, `WebSite`, `BreadcrumbList`, `Article`, `SoftwareApplication`, `FAQPage`) with `@context: "https://schema.org"`.
- Rich snippet eligible with zero syntax or property validation warnings.

### 3. Uncompromising Semantic HTML & Heading Hierarchy
- Exactly **one** semantic `<h1>` tag per page, expressing the primary topical entity.
- Strict heading hierarchy (`h1 -> h2 -> h3`) with zero skipped levels.
- 100% image `alt` attribute coverage (descriptive keywords for content images, empty `alt=""` only for pure decorative SVGs).
- Native semantic elements (`<main>`, `<article>`, `<nav>`, `<header>`, `<footer>`, `<aside>`) instead of nested `<div>` soup.

### 4. Hermetic Indexability & Canonical Integrity
- Every document must define an explicit self-referential `<link rel="canonical" href="...">` to prevent duplicate parameter penalties.
- Meta robots directives (`index, follow`) must be explicitly declared and verified against `robots.txt`.
- Complete OpenGraph (`og:title`, `og:description`, `og:image`, `og:url`) and Twitter card metadata for social preview parity.

### 5. Crawl Budget & Internationalization Efficiency
- Zero internal 301/302 redirect hops or broken 404 links in primary navigation.
- Clean XML Sitemap declaration with precise `<lastmod>` timestamps.
- Explicit language declaration (`<html lang="en">`) and `hreflang` annotations for multi-locale routing.

## 🚫 VISCERAL REJECTION TRIGGERS (ZANE'S ZERO TOLERANCE)

1. **Multiple or Missing `<h1>` Tags:** Multiple primary titles fragment page topic signals and destroy search relevance.
2. **Missing Canonical URL:** Exposing query parameters without a canonical tag triggers severe duplicate index penalties.
3. **Empty Hydration Ghost DOMs:** Client-side-only rendering that serves blank HTML shells before JavaScript execution.
4. **Layout Shift Jitter (CLS > 0.1):** Unsized images or banner ads popping into view and pushing reading content down.
5. **Missing or Broken Schema.org JSON-LD:** Failing to feed structured semantic graphs directly to search spiders.
