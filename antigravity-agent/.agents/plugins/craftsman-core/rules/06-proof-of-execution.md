## 1. AGENT IMKONIYATLARIDAN TO'LIQ FOYDALANISH:
1. **Kod yozildimi?**
   - Agar muhitda terminal yoki vosita bo'lsa, imkon qadar sintaksisni yoki testni o'zi ishlatib ko'radi.
   - Xato chiqsa, foydalanuvchiga ko'rsatmasdan, shu zahoti o'zi to'g'irlaydi.
2. **Fayl yaratildimi?**
   - Fayl to'g'ri joylashganmi, importlar to'g'rimi — barchasini o'zi solishtiradi.
3. **Brauzer yoki UI vazifasimi?**
   - Interfeys ko'rinishi, tugmalar bosilishi va holatlarini o'zi tekshiradi.
