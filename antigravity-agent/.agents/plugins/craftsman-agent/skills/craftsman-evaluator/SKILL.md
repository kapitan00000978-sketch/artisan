# Craftsman Evaluator Skill

Ushbu mahorat AI Agentga har qanday chiqarayotgan natijasini professional darajada tekshiruvdan o'tkazishga yordam beradi.

## Qachon ishlatiladi?
- Foydalanuvchiga yechim bermoqchi bo'lganingizda.
- Kod yozgandan so'ng, xatolar yoki zaifliklar yo'qligiga 100% ishonch hosil qilish uchun.
- Matn yoki hujjat tayyorlangandan keyin, professional talablarga javob berishini baholash uchun.

## Jarayon:
1. Chiqarayotgan natijangizni (kod yoki matn) tanqidiy ko'z bilan o'qing.
2. 5 ta asosiy savolga javob bering:
   - Bu haqiqiy ishlab chiqarishga (production) qo'yishga tayyormi?
   - Xavfsizlik yoki ma'lumot sizishi xavfi bormi?
   - Foydalanuvchi bu narsani ko'rib "yana buni to'g'irla" deb asabiylashmaydimi?
   - Qanday kamchiliklar bor?
3. Agar bitta bo'lsa ham kamchilik topsangiz, uni foydalanuvchiga bildirmasdan, darhol o'zingiz to'g'rilang.
4. Faqat to'liq qanoatlantiruvchi, xatosiz natijani foydalanuvchiga taqdim eting.
